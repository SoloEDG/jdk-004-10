# VOID SIGNAL · 虚空信号

## 安装

Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## 测试

```sh
npm test          # 引擎规则、机库档案与组件冒烟测试（Node test runner）
npm run test:e2e  # Playwright 端到端测试（需本机可用的 Chromium）
```

## 局外机库（v2）

行动之间可在「局外机库」为下一局配置出发装备，配置在点击开始行动时锁定为
本局快照，战斗中打开机库仅可查看，不能无成本换装。

- **初始武器**：脉冲（标配）/ 环轨飞刃 / 新星爆发，1–3 件，禁止重复。
- **机体改装**：机架与核心两个互斥槽位，每组至多一项；改装会实时折算为
  有效参数（生命、移速、伤害、射速、装甲）并在右侧预览。
- **规则校验**：保存前经过武器规则与生存下限校验（生命 ≥ 60、移速 ≥ 120），
  非法配置无法保存。
- **材料经济**：行动结束按 `击杀×2 + 波次×8 + 撤离加成 40` 结算可消费材料，
  以 `runId` 去重，重复打开结算不会重复发放。
- **原子购买**：机库装配先校验、再整档写回本地存储；存储配额不足时余额
  原样保留并提示失败，不会出现材料已扣但装配未保存的状态。失败的结算会
  进入重试队列，存储恢复后自动补写。
- **档案迁移**：v1 裸行动记录数组首次读取时自动迁移为 v2 档案
  （`localStorage` 键 `neon-survivor.profile.v2`），缺失的机库与材料字段
  以默认配置回填，迁移记录保留在档案的 `migrations` 字段中可追溯。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8084 。可通过 PORT 环境变量修改端口。
